# 🎮 Hangman - Word Quest

A fun, text-based Hangman game built using Python.

## ✨ Features

- 🎯 Three difficulty levels: Easy, Medium, and Hard
- 💜 Neon-style terminal colors
- ❤️ Six incorrect guesses allowed
- 💡 Hints to help guess the word
- 🏆 Score system and victory bonus
- 🎨 ASCII Hangman drawing
- 🔄 Play again option
- 🐍 Uses Python built-in modules only

## 🚀 How to Run

1. Install Python 3.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run:

   ```bash
   python hangman.py
   ```

## 🎮 How to Play

- Choose a difficulty level.
- Guess one letter at a time.
- Type `H` to use a hint.
- Type `QUIT` to end the current round.
- Win points by guessing correctly.
- Avoid six incorrect guesses!
